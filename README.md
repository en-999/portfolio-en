# Portfolio

Portfolio personnel de Marc Enzo Bitibaly, construit avec React, TypeScript et Vite.

## Démarrer le projet

```bash
npm install
npm run dev
```

Le site sera disponible sur l’URL indiquée par Vite, généralement `http://localhost:5173`.

## Construire pour la production

```bash
npm run build
npm run preview
```

## Personnalisation

Les textes et projets de démonstration sont dans `src/App.tsx`. Les couleurs, typographies et mises en page sont dans `src/styles.css`.

Le CV PDF original est volontairement exclu du dépôt pour protéger les informations personnelles qu’il contient.
